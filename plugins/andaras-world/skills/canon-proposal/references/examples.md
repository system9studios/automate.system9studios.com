# Examples

Setting details below are stand-ins. Real ones come from the canon pages.

## Triggers
**Prompt:** "OK, portals: new ones can still open but only in unstable regions, and nobody can open one on purpose. Write it up."
**Behavior:** Loads canon-proposal. Reads the cosmology page's section on portals. Creates `docs/canon/portals-travel.md` on branch `canon/portals-travel` with `Status: proposed`, *Decided by the owner* listing both rules, marks derived details `[PROPOSED]` (e.g. how often they open), adds a layer table (Public: portals open in the wastes; Rumor: someone has opened one), lists *Tracker impact*: resolves "whether new portals can still open" and "whether they can be opened deliberately"; partially addresses "consequences of travel through them". Commits, asks before pushing, and reports the path and one next action.

**Prompt:** "Let's change the cost of casting so it's cumulative."
**Behavior:** The cosmology page is approved, so confirms the owner has decided the change, then edits that page in place: changed lines and knock-on effects tagged `[PROPOSED]`, a `**Revisions:**` entry added, status line left for the owner to bump. Creates no amendment page, and leaves the PR open until the owner bumps the version.

## Stops
**Prompt:** "Write up the section on powers of the mind."  (nothing decided yet)
**Behavior:** Doesn't draft. Frames the tracker's open questions for that section (origin, prevalence, categories, costs) as options with consequences, recommends one set, asks the owner to decide.

## Non-triggers
- "Design the militia commander" → content-sheet.
- "Does this room description contradict canon?" → canon-check / line-edit.
